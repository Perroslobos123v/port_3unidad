# Configuración de red y conectividad remota

Módulo 1 de Microsoft SQL Server. Cinco actividades para que tu servidor reciba conexiones de otros equipos de forma controlada.

51433

El puerto fijo por donde entrará toda la comunicación

## Resumen del módulo

| Actividad | Trabajo realizado | Resultado esperado |
| --- | --- | --- |
| 1 | Identificar instancia SQL Server | Servicio activo |
| 2 | Habilitar TCP/IP | Protocolo Enabled |
| 3 | Configurar puerto estático | Puerto 51433 |
| 4 | Habilitar conexiones remotas | Conexiones remotas permitidas |
| 5 | Configurar firewall | Regla TCP 51433 creada |

Con estas cinco configuraciones se identifica la instancia, se habilita TCP/IP, se fija el puerto, se permiten las conexiones remotas y se abre el firewall solo para lo necesario. El entorno queda listo para conexiones de red controladas.
