Práctica 1.6: Identificar el método de autenticación

Entorno: SQL Server Management Studio (SSMS)  |  Instancia: localhost (15.0.2210.4 - sa)  |  Servidor: PERRITOJR

SECTOR ASTRAL // ENIGMA & OUTWORLD DESTROYER • DEFENSA DE DATOS

Consulta 1: telemetría de conexión actual

Ejecútala en SSMS, de preferencia con USE GradosTitulos; GO antes:

-- Grados y títulos --
SELECT
    @@SERVERNAME      AS NombreServidor,
    SYSTEM_USER       AS UsuarioDelSistema,
    ORIGINAL_LOGIN()  AS LoginOriginal,
    SUSER_SNAME()     AS LoginActual,
    DB_NAME()         AS BaseDatosActual;

Cómo interpretar el resultado

  • Windows Authentication: UsuarioDelSistema, LoginOriginal y LoginActual salen con formato EQUIPO\usuario o DOMINIO\usuario.
  • SQL Server Authentication: salen con un nombre simple, como sa o login_secretaria.
  • BaseDatosActual: sale GradosTitulos si hiciste el USE. Si no, sale master.

Consulta 2: escaneo de entidades del servidor

Consulta de diagnóstico en sys.server_principals para inspeccionar todos los logins registrados y su método de autenticación:

-- Grados y títulos --
SELECT
    name        AS NombreLogin,
    type_desc   AS TipoAutenticacion,
    is_disabled AS EstaDeshabilitado
FROM sys.server_principals
WHERE type IN ('S', 'U', 'G')
ORDER BY name;

Qué verás en TipoAutenticacion

  • S es SQL_LOGIN (autenticación SQL).
  • U es WINDOWS_LOGIN (cuenta de Windows).
  • G es WINDOWS_GROUP (grupo de Windows).

EstaDeshabilitado vale 0 si el login está habilitado y 1 si está deshabilitado.

También aparecerán logins internos del motor, como sa o NT SERVICE\.... Es normal.

Conclusión del informe de misión

Al ejecutar las consultas se observó que la conexión actual utiliza SQL Server Authentication, ya que el login es sa (en el servidor PERRITOJR, conectado a la base de datos master). El servidor tiene registrados logins de tipo SQL_LOGIN y WINDOWS_LOGIN (incluyendo la cuenta local PERRITOJR\PC, el usuario sa y cuentas internas de servicio).

Nota técnica: para tu captura, type_desc es lo más importante: ahí se ve el método de cada login.
