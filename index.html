HERRAMIENTAS DEL CURSO

Azure y SQL Server

Dos tecnologías de Microsoft que se usan juntas en mis prácticas de bases de datos.

☁

Microsoft Azure

Es la plataforma de computación en la nube de Microsoft. En lugar de comprar y mantener servidores propios, se alquilan recursos por internet y se paga solo por lo que se usa.

¿Para qué sirve?

  • Crear servidores y máquinas virtuales en minutos.
  • Alojar sitios web y aplicaciones con alta disponibilidad.
  • Almacenar archivos y respaldos de forma segura.
  • Ofrecer bases de datos administradas, como Azure SQL Database.
  • Crecer o reducir recursos según la demanda.
▤

SQL Server

Es el sistema gestor de bases de datos relacionales de Microsoft. Guarda la información en tablas relacionadas entre sí y se maneja con el lenguaje T-SQL.

¿Para qué sirve?

  • Crear bases de datos, tablas, esquemas y grupos de archivos.
  • Insertar, consultar, actualizar y eliminar datos con SQL.
  • Garantizar integridad con claves primarias y foráneas.
  • Controlar usuarios, permisos y copias de seguridad.
  • Generar reportes y analizar datos de una organización.
SQL Server guarda y organiza los datos. + Azure lo ejecuta en la nube, sin servidor físico. = Bases de datos accesibles, seguras y escalables.

Unidad 1 · Fundamentos de bases de datos

  • Manual de SQL: sentencias básicas para crear y consultar bases de datos.
  • Diagramas: modelado entidad-relación de Grados y Títulos, Cadena Editorial y Empresa de Material Informático.
  • Scripts SQL: creación de tablas e inserción de 10 datos de prueba en cada caso.

Unidad 2 · SQL Server en Azure

  • Configuración: creación y conexión del servidor y la base de datos Grados y Títulos en Azure.
  • Almacenamiento: esquemas, grupos de archivos (filegroups) y archivos lógicos de datos y de registro.
  • Evidencias: guías de laboratorio, infografías, casos e informes.

Conceptos clave del curso

Base de datosConjunto organizado de información almacenada para consultarla y actualizarla fácilmente.
Clave primaria y foráneaLa primaria identifica cada fila; la foránea relaciona una tabla con otra.
T-SQLLenguaje de SQL Server: DDL para crear estructuras y DML para manejar los datos.
Modelo entidad-relaciónDiagrama que muestra las entidades, sus atributos y cómo se relacionan.
FilegroupGrupo de archivos que organiza dónde se guardan físicamente las tablas.
Archivos .mdf, .ndf y .ldfDatos principal y secundarios (.mdf, .ndf) y registro de transacciones (.ldf).
EsquemaContenedor lógico que agrupa y ordena los objetos de la base de datos.
Servidor lógico en AzurePunto de administración de las bases de datos de Azure SQL, con su firewall y accesos.
